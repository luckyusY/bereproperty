Project Plan — Toolbay Marketplace Prototype

1. Product direction
Create a responsive marketplace for finding construction materials, tools, equipment, and engineering supplies in Rwanda. Prioritize quick search, useful categories, clear prices in RWF, seller trust, availability, and location.

2. First release scope
- Marketplace home with branded navigation, search, category shortcuts, discovery tabs, filters, and product cards.
- Search listings by product or seller; filter by category and sort by relevance, price, or newest.
- Product detail dialog with seller, location, stock, price/unit, and contact action.
- Saved items and cart interactions with visible state; mobile-friendly layout.
- Seed realistic demo listings in RWF. Keep data local and clearly prototype-ready.

3. Build approach
Use a lightweight React + Vite frontend with custom CSS and inline SVG icons. Keep sample catalog data separate from presentation so a backend can replace it later. Implement accessible controls and responsive states without requiring external services.

4. Later phases
- Accounts, seller onboarding, verified business profiles, inventory management.
- Rwanda-specific delivery/pickup and quote workflows.
- Backend catalog, search, moderation, payments, messaging, analytics, and admin tools.

5. Acceptance checks
- Core home screen loads cleanly at desktop and mobile widths.
- Search, category, sort, save, cart, and product detail controls respond.
- RWF pricing and seller/location/availability are easy to scan.
- No backend or payment claims in this prototype.
